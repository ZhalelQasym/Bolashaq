### 🛠️ Стек и архитектура
- **Генерация и сборка:** Freebuff CLI (консольный AI-инструмент)
- **Развертывание (Деплой):** Vercel Production
- **Использованные AI / API:** Google Gemini,Claude.

### 💡 Что это решит и какой вклад?
Уменьшение количества студентов, бросающих учебу на первых курсах из-за неверного выбора.
Рост квалифицированных специалистов, работающих точно по своей специальности.
Школьники из регионов и сел получают качественную профориентацию наравне со столицей.

### 🧪 Тестовый сценарий 
1. Перейдите по ссылке на Vercel (указана выше).
2. Для наблюдения за работой ИИ,вам нужно кнопку "Тест" сверху от главной страницы,затем пройти тест и увидит результат.
В добавок,вы можете нажать на "Сравнение" и сравнить между собой университеты,но для начала вам нужно выбрать их в пункт "Каталог"
